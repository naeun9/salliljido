# 홈 화면 디자인 변경 기록

이 문서는 홈 화면 디자인 수정 과정과 현재 적용된 시각 기준을 정리한다. 디자인 작업은 기존 서비스의 기능, 데이터 흐름, API, 라우팅, 상태 관리 구조를 유지하면서 UI만 확장하는 방식으로 진행했다.

## 1. 디자인 원칙

홈 화면은 기존에 사용하던 디자인 시스템을 그대로 유지한다.

- 아주 옅은 회색 배경 위에 흰색 카드를 배치한다.
- 진녹색을 주요 숫자, 라벨, 진행 상태와 강조 요소에 사용한다.
- 카드는 얇은 연회색 테두리와 기존 `border-radius`를 사용한다.
- 그림자는 최소화하고 카드 사이에는 넉넉한 여백을 둔다.
- Pretendard 기반의 기존 글꼴 체계를 유지한다.
- 제목, 부제목, 본문, 보조 문구의 상대적인 크기와 굵기 차이를 유지한다.
- 버튼, chip, label은 기존 pill 형태와 색상 토큰을 재사용한다.
- 새로운 디자인 시스템이나 외부 차트 라이브러리를 도입하지 않는다.

주요 디자인 토큰은 `src/styles/tokens.css`에 정의되어 있다. 홈 화면 전용 스타일은 `src/pages/Home.module.css`과 `src/pages/Home/*.module.css`에서 관리한다.

## 2. 문제 정의 데이터 섹션 추가

커밋: `1cfbd4f feat: add problem statement data cards`

기존 홈 화면은 다음 순서로 구성되어 있었다.

```text
히어로 → 서비스 소개 4 STEP → 지역 소개 → 지원사업 → 마지막 CTA
```

서비스 소개 전에 사용자가 지역 여행의 문제를 먼저 이해할 수 있도록 문제 정의와 데이터 시각화 영역을 추가했다.

### 문제 정의

제목:

> 상권이 사라진 지역, 여행을 ‘계획’하는 것부터 장벽입니다.

리드 문구는 인구 유출로 지역의 생활 상권이 줄어들고, 여행자가 숙소와 카페 같은 기본 정보조차 찾기 어려워진 상황을 설명한다.

### 데이터 카드

세 개의 카드는 동일한 높이와 내부 정렬을 사용한다. 숫자, 그래프, 본문, 출처의 수직 위치를 통일해 카드 사이의 비교가 쉽도록 구성했다.

#### 원인

- 핵심 수치: `40%`
- 내용: 전국 시군구 약 40%가 인구감소지역으로 지정
- 설명: 거주민 감소가 식당, 카페, 생활 서비스와 여행 인프라의 축소로 이어지는 관계
- 출처: 행정안전부 「인구감소지역 지정 고시」

#### 현상

- 핵심 수치: `12개 지역`
- 내용: 파일럿 29곳 중 등록 카페가 5건 미만인 지역
- 설명: 카페 정보조차 부족한 지역에서는 며칠간 머물 생활 동선을 구성하기 어려운 상황
- 출처: 한국관광공사 TourAPI 및 자체 실측 · 2026.09

#### 결과

- 핵심 수치: `14개 지역`
- 내용: 파일럿 29곳 중 온라인 숙박 정보가 20건 미만인 지역
- 설명: 숙박 선택지가 적고 방문이 주말에 집중되어 체류형 일정을 만들기 어려운 상황
- 출처: 한국관광공사 TourAPI · 관광빅데이터 · 2026.09

관련 파일:

- `src/pages/Home.jsx`
- `src/pages/Home/ProblemDataSection.jsx`
- `src/pages/Home/ProblemDataSection.module.css`

## 3. 데이터 시각화 애니메이션

커밋: `4dc3ce7 style: add data visualization animations`

사용자가 데이터 섹션을 처음 확인하는 순간 수치의 의미를 쉽게 인지할 수 있도록 짧은 진입 애니메이션을 적용했다.

### 첫 번째 카드

- 숫자가 `0`에서 `40%`까지 증가한다.
- 진행 막대가 왼쪽에서 40% 지점까지 채워진다.
- 전체 실행 시간은 약 900ms다.

### 두 번째 카드

- 전체 파일럿 지역을 의미하는 dot 29개를 표시한다.
- 처음에는 모든 dot이 연회색이다.
- 왼쪽부터 12개가 순서대로 진녹색으로 변경된다.
- 하단에는 `12 / 29`를 표시한다.
- 전체 실행 시간은 약 750ms다.

### 세 번째 카드

- 숫자가 `0`에서 `14개 지역`까지 증가한다.
- 진행 막대가 `14 / 29`에 해당하는 48.3% 지점까지 채워진다.
- 하단에는 `14곳 / 전체 29곳`을 표시한다.
- 전체 실행 시간은 약 900ms다.

애니메이션 구현에는 `IntersectionObserver`, `requestAnimationFrame`, CSS transition만 사용한다. 화면 진입 시 한 번만 실행하고 observer 연결을 해제한다. `prefers-reduced-motion`이 설정된 환경에서는 움직임 없이 최종 값을 바로 표시한다.

## 4. 반응형 레이아웃과 여백

커밋: `e2dd947 style: refine responsive layout and spacing`

데이터 카드는 화면 폭에 따라 다음과 같이 배치된다.

- PC: 3열
- 태블릿: 2열
- 모바일: 1열
- 380px 이하: 카드 안쪽 여백과 dot 크기를 추가로 축소

모바일에서는 긴 문구의 강제 줄바꿈을 제거하고 제목 크기의 상한을 제한했다. 핵심 숫자는 한 줄로 유지하며, 카드의 고정 최소 높이를 해제해 내용 길이에 따라 자연스럽게 늘어나도록 했다. 출처와 본문 사이에는 충분한 간격을 유지한다.

## 5. 솔루션 전환과 서비스 소개 연결

커밋: `b8fb2b6 style: connect data section with service introduction`

데이터 카드 아래에 문제에서 해결 방법으로 넘어가는 전환 영역을 추가했다.

- Eyebrow: `WHY SALLILJIDO`
- 제목: 인구감소지역의 여행은 검색이 아니라 ‘발굴’이 필요하다는 메시지
- 설명: 여러 공공데이터에 흩어진 숙박, 생활 편의, 관광지, 지자체 지원 정보를 한곳에 모아 지역 발견부터 체류 계획까지 연결한다는 내용

전환 영역과 기존 서비스 소개는 같은 배경색과 최대 너비를 사용한다. 두 섹션 사이의 상하 여백을 조정해 다음 흐름이 하나의 이야기처럼 이어지도록 구성했다.

```text
지역에서 발생한 문제
        ↓
수치와 그래프로 현재 상황 설명
        ↓
검색이 아닌 ‘발굴’이 필요하다는 결론
        ↓
살릴지도의 서비스 소개 4 STEP
```

## 6. 홈 타이포그래피 미세 확대

커밋: `0334695 style: slightly increase global typography scale`

기존 타이포그래피 계층과 크기 비율을 유지하면서 홈 화면의 글자 크기를 약 5% 확대했다.

적용 대상:

- 히어로 제목과 설명
- CTA 버튼
- 섹션 제목과 리드 문구
- 카드 제목과 본문
- 데이터 숫자와 출처
- label과 chip
- 지역 카드 문구
- 서비스 미리보기 내부 문구
- 지원사업 영역
- 마지막 CTA
- 사진 출처와 보조 문구

홈 화면 범위에서 공통 타이포 변수 값을 덮어쓰고, 고정 `px` 또는 `vw`로 정의된 글자 크기도 동일하게 1.05배 조정했다. 단위 없는 `line-height`는 글자 크기에 맞춰 비례하므로 유지했다. 카드 높이, 버튼 높이, 섹션 구조와 주요 여백은 변경하지 않았다.

## 9. 변경하지 않은 영역

이번 디자인 작업에서는 다음 영역을 수정하지 않았다.

- 기존 데이터 값과 데이터 처리 구조
- API 호출과 응답 처리
- 라우팅 경로
- 전역 상태와 Context 구조
- 로그인, 검색, 추천, 계획 편집 기능
- 기존 버튼과 링크의 동작
- 외부 패키지와 npm 의존성

디자인 관련 컴포넌트와 CSS만 수정했으며, 새로운 라이브러리는 추가하지 않았다.
