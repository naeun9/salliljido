→ 플랫폼 > Web 사이트 도메인에 `https://salliljido-taupe.vercel.app` 추가.

### A2. 구글 콘솔 자바스크립트 원본 등록 · **5분 · 코드 작업 아님**

실제 팝업까지 띄워 보니 구글이 막는다:

> Access blocked: Authorization Error — 자바스크립트 출처를 등록하세요.

client_id는 제대로 실려 나가고 GIS 스크립트도 200으로 내려온다. **승인된
자바스크립트 원본**에 두 개를 등록해야 로그인이 완료된다.

- `http://localhost:5173`
- `https://salliljido-taupe.vercel.app`

포트가 옮겨 다니면 등록 주소와 어긋나므로 `vite.config.js`에
`server: { port: 5173, strictPort: true }`를 넣어 뒀다.

### A3. API 장애 중 "이 지역에는 ○○ 정보가 없어요" · **1시간**

`ScheduleTab/ConditionPanel.jsx:104`과 `TimelineItem.jsx:108`의 툴팁이다.
관광공사 목록을 못 받았을 때도 같은 문구가 떠서 **API 장애를 지역 탓으로

심사 중 상류 장애가 없으면 드러나지 않지만, 나면 잘못된 정보가 된다.

## 3. C — 접은 것 (7건)

- **마감 임박 알림 설정** — 카드 하단 "설정하기" 버튼이 design에서도
  `display:none` 하드코딩이라 한 번도 보이지 않는다. 알림 인프라도 없다.
- **"나중에 담기"(계획 밖에서 담기)** — 지금은 "계획 = 화면 하나"라는 전제가
  곳곳에 깔려 있다. 열려면 담은 id를 지역 단위 localStorage에 두고
  PlanEditor가 진입 시 흡수하는 구조가 필요하다.
- **사진 계절 맞추기** — 지역마다 계절이 섞여 있다(정선 겨울, 의성 봄).
  월별로 고르려면 지역당 사진을 더 넣어야 한다.
- **카드에 소개 문구** — 목록 API에 `overview`가 없다. 카드에는 주소를 넣고,
  개요는 상세 모달(`detailCommon2`)에서 보여주는 것으로 정리했다.
- **추천 카드와 지역 소개의 점수 함수 통합** — 이미 `regionProfile.js` 하나를
  공유하므로 실질 문제는 없다. 남은 것은 이름 정리뿐.
- **스캐폴딩 스텁 1개** — `components/cost/CostSummary.jsx`(6줄, 아무 데서도
  import 안 됨). 나머지 스텁 12개는 실구현으로 바뀌거나 삭제됐다.
- **마이페이지 데모 카드(seedRegions/seedRoutines)** — design은 처음 방문에도
  비어 보이지 않게 지역 3개·계획 2개를 섞어 보여준다. 저장한 적 없는데
  보이면 신뢰를 해쳐서 **일부러 넣지 않기로 결정**했다(재검토 불필요).

## 5. 계속 지켜야 할 것

### 디자인 보존 현황

- 색상·모서리·그림자는 design과 100% 일치(자동 대조 완료).
- **폰트 크기는 의도적으로 다르다.** 2026-09-13에 스케일을 한 단계 올렸다
  (0.5px 단위 28종 → 14종, 본문 16px·보조 14px·최소 13px). 값이 어긋난
  것이 아니라 지시에 따라 바꾼 것이므로 "원본과 대조"할 때 이 예외를
  기억할 것. 옮긴 표는 `src/styles/tokens.css` 머리말에 있다.
- 폰트 상향의 여파로 깨진 곳 1건을 찾아 고쳤다(2026-09-13, 390px 실측):
  최종 계획 지표 카드에서 "595,000원"의 "원"만 다음 줄로 넘어갔다.
  칸 좌우 여백을 26px → 16px로 좁혀 해결했다(`MetricsRow.module.css`,
  좁은 화면에서만). 나머지 화면(홈·조건 선택·지역 소개·계획 편집·지원
  프로그램·최종 계획)은 390px에서 잘림·넘침이 없었다.
- 남은 차이 1건: PlanEditor 배너 제목의 전환 방식(위 B8).

### 코드 규칙

- **모듈 CSS에 `animation:`을 새로 쓰면 전멸한다.** CSS 모듈이 클래스명을
  해시하면서 `@keyframes` 이름과 어긋나는 함정이 있다(2026-08-29에 한 번
  겪었다). 전역 클래스(`slj-anim-*`)를 쓰거나 `@keyframes`를 그 모듈 안에
  정의할 것.
- 한 파일 300줄을 넘기지 말 것(CLAUDE.md). 지금 넘는 파일 5개는 아래 B10.

### 화면을 눈으로 확인하는 방법

이 저장소에는 스크린샷 도구가 없지만 로컬에 크롬이 있으면 확인할 수 있다.

```
npm run build && npx vite preview --port 4173
"/c/Program Files/Google/Chrome/Application/chrome.exe" --headless=new   --disable-gpu --hide-scrollbars --virtual-time-budget=9000   --window-size=500,900 --screenshot=shot.png "http://localhost:4173/"
```

함정 두 가지(2026-09-13에 겪었다):
- **`--window-size`의 폭이 레이아웃에 반영되지 않는다.** 390을 줘도 실제
  레이아웃은 500px로 잡히고 캔버스만 390이 되어, 오른쪽이 잘린 그림을
  보고 "레이아웃이 깨졌다"고 오해하게 된다. 캔버스를 500 이상으로 줄 것.
- **진짜 폰 폭(390px)을 보려면 iframe으로 감싼다.** `dist/`에 아래 같은
  페이지를 두고 `?p=/경로`로 열면 iframe 안이 390px 레이아웃이 된다
  (같은 오리진이어야 렌더된다).

```html
<iframe src="/plan/태안/overview" style="width:390px;height:844px;border:0"></iframe>
```

- `vite preview`는 `vite.config.js`의 개발용 API 플러그인을 태우지 않아
  `/api/*`가 404다. 관광 목록이 "정보를 불러오지 못했어요"로 나오는 것은
  정상이며, 레이아웃 확인에는 지장이 없다. 카카오맵도 키·도메인이 없으면
  목업 폴백으로 뜬다.

### 보안·규정 현황

- 프로덕션 번들에 `TOUR_API_KEY` 값도 변수명도 없다. `src/` 어디에서도
  참조하지 않고 `api/_lib/tourApi.js` 한 곳에서만 `process.env`로 읽는다.
- `.gitignore`에 `.env.local` 포함. 커밋 이력에도 없다.
- 파일 쓰기 코드 없음. 관광 콘텐츠 캐시는 서버리스 함수의 메모리 `Map`과
  `exploreListings.js`의 세션 캐시뿐이라 실시간 호출 원칙을 지킨다.
- localStorage에는 로그인 상태와 사용자가 저장한 것(지역 short / 계획 /
  프로그램 id)만 들어간다. 관광공사 응답은 이름·주소까지 저장하지 않고
  id만 남긴다(`utils/planSnapshot.js`).
- **출처 표기 위치가 2026-09-13에 바뀌었다.** 예전에는 푸터 + 지역 소개
  하단 + 둘러보기 탭 + 예상 비용 패널 네 곳이었는데, 푸터를 홈 전용으로
  되돌리면서 한 줄짜리 `DataSourceNote`로 옮겼다. 지금 붙는 곳:
  홈(푸터) · `/find/result` · `/region/*` · `/plan/:id` · `/mypage` ·
  `/plan/:id/overview`(자체 섹션). 새 화면을 만들 때는
  `components/common/Layout.jsx`의 `usesTourData()`에 경로를 더할 것.
